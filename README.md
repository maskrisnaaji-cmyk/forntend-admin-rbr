# Rumah Budaya Ratna - Web Admin Panel

Pusat kendali dan manajemen operasional berbasis web untuk platform **Rumah Budaya Ratna**. Aplikasi ini digunakan oleh administrator untuk mengelola konten, inventaris, reservasi, dan data pengguna secara real-time.

## 🛠️ Deskripsi Proyek
Web Admin ini dibangun menggunakan arsitektur modern Next.js 15 dengan App Router, TypeScript untuk type safety, serta Tailwind CSS v4 untuk konsistensi desain UI/UX.

## 📦 Daftar Library / Package yang Digunakan
- **Next.js** (`15.1.7`) - React Framework
- **React** (`19.0.0`) - UI Library
- **Tailwind CSS** (`v4`) & `@tailwindcss/postcss` - Styling Engine
- **TypeScript** - Type Safety
- **Lucide React** - UI Icons

## 🚀 Panduan Menjalankan Aplikasi

Jalankan perintah berikut secara berurutan di terminal:

```bash
git clone [https://github.com/maskrisnaaji-cmyk/forntend-admin-rbr.git](https://github.com/maskrisnaaji-cmyk/forntend-admin-rbr.git)
cd forntend-admin-rbr
npm install
npm run dev
